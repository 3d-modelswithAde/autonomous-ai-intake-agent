## 1. Executive Summary & Purpose

The **Autonomous AI Intake Agent** is an enterprise-grade customer communication and operations automation engine designed for **Marcus Vance Automotive**. It processes inbound customer emails from Gmail, synchronizes contacts and tickets with **HubSpot CRM**, extracts structured vehicle and repair data using zero-hallucination AI classification, verifies vehicle model availability against an approved catalog, calculates deterministic repair prices from a strict pricing matrix, alerts service advisors across dedicated **Telegram** channels, dispatches automated transactional emails via **Gmail**, and maintains an immutable audit trail in **Google Sheets**.

## 3. Core Business Invariants & Architectural Rules

1. **CRM Support Ticket First (Rule #6)**:
   The HubSpot Support Ticket **must always** be created and assigned a tracking reference **prior to** AI extraction, pricing calculation, Telegram alerting, or email replies. No inquiry is ever processed without a guaranteed CRM ticket ID.
2. **Deterministic Dual-ID Scheme (Rule #7)**:
   - **Internal Inquiry ID**: Machine-level UUID (`inq_<uuid>`) for database keys, idempotency, and system tracing.
   - **Customer Tracking Number**: Human-readable format (`TRK-YYYYMMDD-XXXX`), present in all email subjects, CRM tickets, Telegram cards, and Google Sheets rows.
3. **Absolute Sensitivity Quarantine (Rules #5, #12, #13)**:
   Any inquiry mentioning refunds, chargebacks, payment disputes, legal action, attorneys, lawsuits, court, BBB, regulatory complaints, damage claims, or severe hostility is quarantined immediately. It routes strictly to `🔴 Manual Review`, updates HubSpot to Stage 2, logs to Google Sheets, and **automated customer communication is completely suppressed**.
4. **Zero-Hallucination Deterministic Pricing (Rules #4, #10, #11)**:
   Prices are never estimated, guessed, or generated by AI. Pricing is derived strictly from a static JavaScript rate matrix based on Vehicle Tier and Service Code. Unlisted services, unlisted vehicle models, or unknown tiers (`unknown_manual`, `tier_4_exotic_commercial`) force `pricing_status = "manual_quote_required"` with `estimated_cost = null`.
5. **Vehicle Model Catalog Check (Rule #5)**:
   The extracted vehicle model is validated against the shop's supported vehicle model catalog. If the model is not found, the system does not invent a match, marks `vehicle_model_found = false`, assigns `unknown_manual` tier, routes to manual estimate confirmation, and notifies the customer that an advisor is reviewing parts requirements.
6. **Strict Dual-Intent Classification**:
   - `primary_intent`: Exactly one of `Sales`, `Complaint`, `Payment`, `Booking`, `Internal Task`.
   - `secondary_intent`: Exactly one of `routine_maintenance`, `mechanical_repair`, `body_paint`, `diagnostic`, `quote_inquiry`, `appointment_reschedule`, `general_inquiry`, `other`.
7. **Master Activity Audit Trail (Rule #8)**:
   Every state transition is written to the 26-column `Master_Intake_Log` in Google Sheets.
8. **Graceful Degradation (Rule #9)**:
   Missing data or system failures trigger polite follow-up or administrative error logging without unhandled crashes.

## 4. HubSpot CRM Configuration & Property Limits

### Strict Custom Property Constraint
**Do NOT create additional custom properties in HubSpot.** The system must strictly adhere to the agreed properties:

| Property Internal Name | Type | Description |
| :--- | :--- | :--- |
| `inquiry_id` | Single-line Text | Internal UUID generated at intake (pre-existing) |
| `tracking_number` | Single-line Text | Human-readable tracking number (`TRK-YYYYMMDD-XXXX`) |
| `inquiry_category` | Dropdown Select | Primary intent / category |
| `vehicle_year` | Number | 4-digit manufacturing year |
| `vehicle_make` | Single-line Text | e.g., Toyota, Honda, Ford |
| `vehicle_model` | Single-line Text | e.g., Camry, F-150, RAV4 |
| `vehicle_vin` | Single-line Text | 17-character VIN (if provided) |
| `vehicle_tier` | Dropdown Select | `tier_1_sedan_coupe`, `tier_2_suv_crossover`, `tier_3_truck_van_diesel`, `tier_4_exotic_commercial`, `unknown_manual` |
| `services_requested` | Multi-line Text | Extracted services |
| `estimated_cost` | Currency (USD) | Total estimated cost calculated from pricing table |
| `is_sensitive` | Single Checkbox | `true` if quarantined |

*All additional detailed summaries, sentiment scores, and action logs are stored in the standard ticket `description` field and Google Sheets rather than creating new HubSpot properties.*

### Ticket Pipeline Stages (`automotive_intake_pipeline`)
- Stage 1: `New Inquiry` (`1` / `new_inquiry`) — Created immediately at intake.
- Stage 2: `Manual Review Required` (`2` / `manual_review`) — Sensitive/escalated inquiries.
- Stage 3: `Needs Customer Info` (`3` / `needs_info`) — Missing vehicle or service details.
- Stage 4: `Quote Generated / Auto-Responded` (`4` / `quote_generated`) — Price calculated & confirmed.
- Stage 5: `In Progress / Assigned` (`5` / `in_progress`) — Claimed by service advisor.
- Stage 6: `Closed - Resolved` (`6` / `closed_resolved`) — Completed.

## 6. Telegram Alerting Strategy

- **`🔴 Manual Review` (Urgent Escalation)**: For all inquiries where `is_sensitive == true`. Formatted with high-visibility alerts containing customer details, trigger phrase, AI summary, and direct links.
- **`📥 Intake Notifications` (Operations)**: For routine inquiries, auto-quotes sent, and missing-info follow-up notices.
- **`⚠️ System Alerts` (Engineering & Health)**: For uncaught execution failures with node name and stack trace.
